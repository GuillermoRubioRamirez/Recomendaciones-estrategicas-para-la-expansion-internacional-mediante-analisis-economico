## Modelos predictivos de PIB e IPC para apoyo a decisiones de inversión internacional

Proyecto desarrollado junto a Laboral Kutxa con el objetivo de apoyar decisiones de inversión en mercados internacionales mediante modelos predictivos del PIB e IPC.

Se aplicaron técnicas avanzadas de análisis de series temporales y modelado estadístico (SARIMA y ARIMA) para estimar los indicadores económicos clave del último trimestre de 2022 en Italia, validando los resultados frente a datos reales e instituciones oficiales como ISTAT.

Para la selección y validación de los modelos se utilizaron criterios como AIC, AICc y BIC, combinados con validación cruzada temporal y análisis de residuos (ruido blanco), garantizando así la fiabilidad y robustez de las estimaciones. Adicionalmente, se construyó una base de datos temporal en InfluxDB para la gestión eficiente de datos macroeconómicos, permitiendo consultas dinámicas para el análisis exploratorio y comparativo entre países.

El proyecto también incluyó recomendaciones de inversión para clientes en función del contexto económico italiano, explorando sectores estratégicos como el inmobiliario, tecnológico y financiero, y considerando tanto oportunidades como riesgos derivados de la deuda pública y la inflación post-COVID.
